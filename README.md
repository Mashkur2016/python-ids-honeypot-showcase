# Python IDS & Honeypot Toolkit

> **Showcase repository.** This repo documents the project (architecture, design decisions, results). The source code is private; walkthroughs and code review are available on request.

**Context:** BSc (Hons) Cyber Security individual project (2025)

## What it is
A modular Python Intrusion Detection System combined with honeypot services (simulated SSH and HTTP) that lure and log attacker activity in a lab environment.

## Features
- Flask web dashboard with real-time WebSocket alerts
- Configurable detection rules
- Automatic firewall blocking of malicious IPs
- Email notifications for high-severity events
- IP geolocation / ISP threat intelligence
- Whitelist / blocklist management (MySQL)
